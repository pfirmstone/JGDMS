Codebase Safety API — BAE and Verdict Registry

Public API interfaces and value types for the two services that together enforce the JGDMS safe-codebase guarantee: the {@link au.net.zeus.jgdms.api.codebase.BytecodeAnalysisEngine} (BAE) and the {@link au.net.zeus.jgdms.api.codebase.VerdictRegistry} (VR).

Services

{@link au.net.zeus.jgdms.api.codebase.BytecodeAnalysisEngine}
Remote interface for the BAE service. It analyses the bytecode of a JAR and returns a signed {@link au.net.zeus.jgdms.api.codebase.JarAnalysisReport} that records whether the bytecode was judged safe, unsafe, or indeterminate. The BAE runs in a dedicated Phoenix activation group with restrictive security permissions so that analysing malicious bytecode cannot compromise the broader system.
{@link au.net.zeus.jgdms.api.codebase.VerdictRegistry}
Remote interface for the VR service. Registered BAE instances submit {@link au.net.zeus.jgdms.api.codebase.JarAnalysisReport} records via {@code submitReport}. When a configurable quorum of independent BAEs agree, the registry stores a {@link au.net.zeus.jgdms.api.codebase.RegistryVerdict} that downstream consumers can retrieve and trust. The VR holds the registry signing key and is completely isolated from BAE instances at the process and network level.

Value types

{@link au.net.zeus.jgdms.api.codebase.VerdictType}
Enumeration of possible analysis outcomes: {@code SAFE}, {@code UNSAFE}, and {@code INDETERMINATE}.
{@link au.net.zeus.jgdms.api.codebase.JarAnalysisReport}
A BAE-signed analysis report for a specific JAR, carrying the content hash, per-class analysis results, declared permissions, codebase URIs, and the BAE's digital signature.
{@link au.net.zeus.jgdms.api.codebase.RegistryVerdict}
A registry-countersigned verdict stored by the VR after a quorum of BAEs agree. This is the artifact that clients ultimately retrieve and verify.
{@link au.net.zeus.jgdms.api.codebase.CrashReport}
Submitted by a BAE when it encounters a fatal error during analysis, so that the registry can track engine reliability.

URI handling

All codebase URLs are carried as {@link org.apache.river.api.net.Uri} instances (RFC 3986 strict syntax) throughout this API. {@code java.net.URL} is used only at the point of making a network connection, preventing SSRF and DNS-rebinding attacks that arise from premature URL resolution.
