JGDMS Shared Smart-Proxy Infrastructure

Reusable, download-safe proxy base classes for all JGDMS services. Classes in this package are placed on the service's codebase and are therefore downloaded by clients; they must not reference any server-side implementation classes.

{@link au.net.zeus.jgdms.proxy.AbstractSmartProxy}

Abstract base class for every JGDMS smart proxy. Implements {@link java.io.Serializable}, {@link org.apache.river.api.io.AtomicSerial}, {@link net.jini.export.ProxyAccessor}, {@link net.jini.id.ReferentUuid}, and {@link net.jini.admin.Administrable}. Subclasses need only supply:

  • A no-extra-state {@link org.apache.river.api.io.AtomicSerial.GetArg} constructor that calls {@code super(args)}.
  • A direct constructor that calls the protected two-argument constructor {@code AbstractSmartProxy(server, proxyID)}.

Before any field is assigned the static {@code checkServer()} helper validates that the deserialized server stub implements every interface declared by the concrete proxy class plus the mandatory infrastructure interfaces ({@link net.jini.export.CodebaseAccessor}, {@link net.jini.lookup.ServiceProxyAccessor}, {@link net.jini.lookup.ServiceAttributesAccessor}, {@link net.jini.lookup.ServiceIDAccessor}, {@link net.jini.admin.Administrable}, {@link net.jini.admin.JoinAdmin}, {@link org.apache.river.admin.DestroyAdmin}). This ensures that a maliciously crafted serialization stream cannot inject a stub that lacks the expected remote interface set.

The nested abstract class {@link au.net.zeus.jgdms.proxy.AbstractSmartProxy.ConstrainableSmartProxy} extends {@code AbstractSmartProxy} and additionally implements {@link net.jini.core.constraint.RemoteMethodControl}. Concrete constrainable proxies extend this class and obtain full constraint-propagation boilerplate for free.

{@link au.net.zeus.jgdms.proxy.AdminProxy}

Concrete, ready-to-use administration proxy returned by {@link au.net.zeus.jgdms.service.support.AbstractJiniService#getAdmin()}. Implements both {@link net.jini.admin.JoinAdmin} (controlling lookup-service registration) and {@link org.apache.river.admin.DestroyAdmin} (shutting the service down). All eleven delegation methods use typed transient fields ({@code joinAdmin}, {@code destroyAdmin}) that are populated and validated in every constructor path, eliminating runtime casts at call sites.

The static {@code AdminProxy.create(server, proxyID)} factory automatically returns the inner {@code ConstrainableAdminProxy} variant when the server stub implements {@link net.jini.core.constraint.RemoteMethodControl}. {@code ConstrainableAdminProxy} carries a full {@code methodMapArray} and uses {@link org.apache.river.proxy.ConstrainableProxyUtil} to translate and verify {@link net.jini.core.constraint.MethodConstraints} across the proxy → server boundary.
