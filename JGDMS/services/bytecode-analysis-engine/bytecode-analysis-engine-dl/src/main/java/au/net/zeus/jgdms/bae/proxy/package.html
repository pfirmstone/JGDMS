Bytecode Analysis Engine — Client-Side Proxy

Download-safe proxy classes for the Bytecode Analysis Engine (BAE) service. These classes appear on the BAE service's codebase and are downloaded by clients; they must not reference any server-side implementation classes.

{@link au.net.zeus.jgdms.bae.proxy.BytecodeAnalysisEngineProxy}

Concrete smart proxy for the BAE service. Extends {@link au.net.zeus.jgdms.proxy.AbstractSmartProxy} and implements {@link au.net.zeus.jgdms.api.codebase.BytecodeAnalysisEngine}. All remote method calls are forwarded to the inner server stub which is validated on construction and during {@link org.apache.river.api.io.AtomicSerial} deserialization.

The static {@code create(server, proxyID)} factory automatically returns the nested {@code ConstrainableBytecodeAnalysisEngineProxy} variant when the server stub implements {@link net.jini.core.constraint.RemoteMethodControl}, enabling full constraint propagation for JERI-based deployments without any change to client code.

@since 3.1
