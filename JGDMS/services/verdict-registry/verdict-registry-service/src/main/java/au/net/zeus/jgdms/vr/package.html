Verdict Registry — Service Implementation

Server-side implementation of the {@link au.net.zeus.jgdms.api.codebase.VerdictRegistry} (VR) service. Code in this package runs inside the VR process and must not appear on the service codebase.

{@link au.net.zeus.jgdms.vr.VerdictRegistryImpl}

The non-activatable implementation of the VR service. Extends {@link au.net.zeus.jgdms.service.support.AbstractJiniService} and provides:

  • Engine registration / revocation — BAE instances register their public key with the VR to participate in quorum voting.
  • Report submission and quorum logic — incoming {@link au.net.zeus.jgdms.api.codebase.JarAnalysisReport} records are verified against the submitting BAE's registered key. When the configured quorum of independent BAEs agree on an outcome, the VR signs and stores a {@link au.net.zeus.jgdms.api.codebase.RegistryVerdict}.
  • Crash reporting — BAEs can submit {@link au.net.zeus.jgdms.api.codebase.CrashReport} records so the registry can track engine reliability and exclude unreliable engines from quorum calculations.
  • Event notification — registered subscribers receive a {@link au.net.zeus.jgdms.vr.proxy.VerdictEvent} whenever a new {@code RegistryVerdict} is stored.
  • Lease management — event subscriptions are managed via {@link au.net.zeus.jgdms.vr.proxy.VerdictEventLease} so that stale subscriptions are automatically reclaimed.

{@link au.net.zeus.jgdms.vr.ActivatableVerdictRegistryImpl}

Phoenix-activatable variant of the VR service. Wraps {@code VerdictRegistryImpl} with the standard JGDMS activatable lifecycle and is started by an activation descriptor rather than {@link net.jini.config.Configuration} directly.

Security model

The VR holds the registry signing key-pair and is the only component that can produce {@link au.net.zeus.jgdms.api.codebase.RegistryVerdict} objects trusted by clients. It must therefore be completely isolated from BAE instances at the process and network level: the VR must not accept inbound connections from sources other than registered BAEs and authorised clients, and it must not initiate outbound connections to arbitrary hosts.
