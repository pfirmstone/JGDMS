## 3. Decisions taken

## 14. Glossary of terms a successor will meet

- SCAP: Standard Codebase Audit Pipeline; produces signed `RegistryVerdict`s (SAFE/DANGEROUS/INCONCLUSIVE), hash-keyed as `urn:sha256:<hash>`.
- Boot window / steady state: `resolve()` first loads (vr==null with server principals present) versus later resolutions. Local digests and `BootstrapPermission` run only in the boot window (RELAYED, cited `PreferredProxyCodebaseProvider:1987-2125`; line numbers move).
- "Shortcut" / "unmarshalled itself": `resolve()` reuses the delivering loader when the codebase path matches, comparing path only; precedes the isolation router.
- `Key`: provider cache key; handler equality includes server constraints but NOT client constraints (Sonnet and Opus corrected the Fable claim).
- Weak path vs verified path: `Security.grant(Class, Permission[])` (loader-wide `ClassLoaderGrant`) versus `Security.grant(Class, CodeSource[], Principal[], Permission[])` (`DigestDomainGrant`). Decision: preparer rejects a provider-loaded proxy with no verified identity, no automatic fallback; the `DynamicPolicy` default throws `UnsupportedOperationException` and the caller must not fall back to the weak path.
- Remote-attested tier: section 3.
- Zone T / `tierAI`: DirtyChai-only; AI may add tests under `test/jdk/ai/` with an `@author` naming the model, shown load-bearing. Not used here.
- Inconclusive grants: `Security` retains a grant per INCONCLUSIVE loader and voids the previous one per loader (`SecurityInconclusiveGrantLifecycleTest` asserts this as intended); Fable review wants a union, and the new verified overload throws for a marked loader.
